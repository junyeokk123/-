# 화재조사관 자격시험 문제풀이

1차 필기(객관식) · 2차 실기(단답형/주관식) 자가학습 퀴즈 앱. 정적 HTML 한 장으로 동작하며, Supabase를 통해 "틀린문제 모음"과 성장 기록을 기기 간(회사 컴퓨터 ↔ 휴대폰) 자동 동기화합니다.

## 배포 (Vercel)

1. 이 저장소를 Vercel에 Import (Framework Preset: **Other**, 빌드 명령 없음 — 정적 파일 그대로 서빙)
2. 배포 후 발급되는 `https://xxx.vercel.app` 주소를 북마크하거나 휴대폰 홈 화면에 추가해서 사용

## Supabase 설정

`index.html` 상단의 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 값을 실제 프로젝트 값으로 채워야 동기화가 활성화됩니다. 테이블 스키마는 `schema.sql` 참고(Supabase SQL Editor에서 실행).

## 동기화 방식

앱 첫 화면에서 "소방서"와 "이름"을 입력하면, 그 조합을 키로 Supabase에 오답 목록과 응시 기록이 저장/조회됩니다. 입력하지 않으면 이 브라우저에만 로컬 저장됩니다.

## 2026-09 업데이트: 새 기능 5종

- **과목별 취약점 통계**: "내 성장 기록" 화면에 과목별 정답률을 취약한(정답률 낮은) 순서로 보여줍니다.
- **오답 재출현 우선순위**: 틀린문제 모음을 다시 풀 때 가장 많이 틀린(miss_count가 높은) 문제가 먼저 나오도록 정렬됩니다.
- **오답에 메모 남기기**: 틀린문제 모음을 풀 때 각 문제 아래에 메모칸이 나타나고, 다른 곳을 클릭하면 자동 저장됩니다.
- **다크모드**: 화면 우측 상단의 🌙/☀️ 버튼으로 전환할 수 있고, 기기별로 선택이 저장됩니다(시스템 설정도 자동 반영).
- **'모르겠음' 선택지**: 객관식 문제에 "🤷 모르겠음"을 선택할 수 있고, 선택 시 오답노트에 자동 추가되어 나중에 다시 풀 수 있습니다.

### DB 마이그레이션 필요

기존에 `schema.sql`을 이미 실행해서 Supabase 테이블이 만들어져 있다면, **`migration_2026-09.sql`의 내용을 Supabase SQL Editor에 한 번 붙여넣고 실행**해야 위 기능들(특히 재출현 우선순위/메모/과목별 통계/안 푼 문제)이 클라우드에도 정상적으로 동기화됩니다. 실행 전에도 이 브라우저 안에서는 정상 동작하며, 마이그레이션 전까지는 새 필드만 다른 기기로 동기화되지 않고 이 기기에만 저장됩니다.

## 2026-09 추가 업데이트: 안 푼 문제 / 조기 제출 / 다시 풀기

- **틀린문제 + 안 푼 문제 함께 풀기**: "틀린문제 모음" 화면이 "틀린문제 · 안 푼 문제 모음"으로 확장됐습니다. 필기/실기 각각 오답 카드와 안 푼 문제 카드가 따로 있고, 그 아래 "🔀 오답 + 안 푼 문제 함께 풀기" 버튼으로 둘을 합쳐서 한 번에 복습할 수 있습니다.
- **큰 문제 세트 조기 제출**: 900문제처럼 많은 문제를 한 번에 선택해도, 화면 하단에 항상 붙어 있는 제출 바에서 지금까지 몇 문제를 풀었는지 보면서 언제든 제출할 수 있습니다. 다 풀지 않고 제출하면 확인 메시지가 뜨고, 안 푼 문제는 자동으로 "안 푼 문제" 목록에 저장되어 나중에 이어서 풀 수 있습니다. 실기에도 카드 화면 하단에 "지금까지 채점 결과 보기" 버튼이 추가되어 같은 방식으로 동작합니다.
- **정답이어도 다시 풀기**: 채점 결과 화면에서 정답으로 맞힌 문제 아래에도 "🔁 오답노트에 추가" / "🔁 안 푼 문제로 추가" 버튼이 나타나, 맞혔더라도 헷갈렸던 문제를 수동으로 복습 목록에 넣을 수 있습니다.
- 이 업데이트는 `ffi_unanswered_mcq`, `ffi_unanswered_practical`이라는 새 테이블을 사용하므로, 위의 DB 마이그레이션(`migration_2026-09.sql`)에 이미 포함되어 있습니다. 아직 실행하지 않았다면 한 번 실행해 주세요.

## 2026-09 추가 업데이트 2: 필기 즉시채점 모드 개선

- **이전 문제로 돌아가기**: 필기 "문제마다 바로 정답 확인"(즉시채점) 모드에서도 "◀ 이전 문제" 버튼으로 앞 문제로 돌아가 내가 골랐던 답과 정답을 다시 확인할 수 있습니다. 이미 답한 문제는 다시 채점되지 않고 그때 결과 그대로 보여줍니다.
- **즉시채점 모드에도 조기 제출 추가**: 지금까지는 "다 풀고 한번에 채점"(일괄채점) 모드에만 화면 하단 제출 바가 있었습니다. 즉시채점 모드로 문제를 풀 때는 이 제출 바가 원래 나타나지 않는 화면 구조라, 대신 문제 카드 아래에 "지금까지 채점 결과 보기 (남은 문제는 안 푼 문제로 저장)" 버튼을 새로 추가했습니다. 이 버튼을 누르면 지금까지 푼 문제는 그대로 채점되고, 아직 도달하지 않은 문제는 자동으로 "안 푼 문제" 목록에 저장되어 나중에 이어서 풀 수 있습니다.

## 2026-09 추가 업데이트 3: 복습 채점 방식 선택 · 즉시채점 다시풀기 · 홈 버튼

- **틀린문제/안 푼 문제 복습도 즉시채점으로**: "틀린문제 · 안 푼 문제 모음" 화면의 필기 섹션에 "다 풀고 한번에 채점" / "문제마다 바로 정답 확인" 라디오 버튼이 추가됐습니다. 오답 카드, 안 푼 문제 카드, 함께 풀기 버튼 중 무엇을 누르든 여기서 고른 방식으로 복습이 시작됩니다. 즉시채점으로 복습할 때도 문제마다 메모를 남길 수 있습니다.
- **즉시채점 중에도 정답을 맞혀도 바로 "다시 풀기" 등록**: 지금까지는 다 풀고 채점 결과 화면에서만 정답 문제에 "🔁 오답노트에 추가" / "🔁 안 푼 문제로 추가" 버튼이 있었는데, 즉시채점 모드는 문제마다 바로 정답을 보여주는 방식이라 그 자리에서 바로 눌러서 헷갈렸던 문제를 등록할 수 있게 했습니다.
- **좌측 상단 홈 버튼**: 화면 좌측 상단에 🏠 버튼이 생겨서, 어떤 화면에 있든 한 번에 모드 선택 화면으로 돌아갈 수 있습니다. 문제를 풀던 중(필기 즉시/일괄채점, 실기 카드)에 누르면 "저장 없이 나가도 되는지" 한 번 확인합니다 — 풀던 내용을 저장하려면 먼저 제출/조기 제출/채점 결과 보기 버튼을 눌러주세요.
